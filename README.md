# Exploración Power Apps

Seminario introductorio para usuarios finales que muestra cómo crear y explorar aplicaciones con Power Apps, integrar Dataverse, Copilot y Power Platform, con requisitos mínimos y enfoque práctico.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [4 Demostración / caso aplicado](Capitulo01/README.md#4-demostración-caso-aplicado)
  - Descripción: Realizar una demostración aplicada que integre la visión general de Power Apps, su relación con Power Platform y el apoyo de Copilot en un flujo de trabajo simple.
  - Duración estimada: 6 min

### Capítulo 2

- [4 Demostración / caso aplicado](Capitulo02/README.md#4-demostración-caso-aplicado)
  - Descripción: Realizar una demostración aplicada para iniciar una aplicación, reconocer la interfaz de diseñador y preparar un lienzo con pantallas, controles y componentes básicos.
  - Duración estimada: 6 min

### Capítulo 3

- [4 Demostración / caso aplicado](Capitulo03/README.md#4-demostración-caso-aplicado)
  - Descripción: Realizar una demostración aplicada para conectar una fuente de datos mediante un conector o Dataverse y visualizar registros básicos considerando seguridad y permisos.
  - Duración estimada: 8 min

### Capítulo 4

- [4 Demostración / caso aplicado](Capitulo04/README.md#4-demostración-caso-aplicado)
  - Descripción: Realizar una demostración aplicada que utilice fórmulas, variables, colecciones, acciones y navegación para validar y guardar datos en una aplicación funcional.
  - Duración estimada: 8 min

### Capítulo 5

- [4 Demostración / caso aplicado](Capitulo05/README.md#4-demostración-caso-aplicado)
  - Descripción: Realizar una demostración aplicada para generar interfaces y fórmulas con Copilot, conectar la aplicación con Power Automate y aplicar buenas prácticas de integración simple.
  - Duración estimada: 10 min

### Capítulo 6

- [4 Demostración / caso aplicado](Capitulo06/README.md#4-demostración-caso-aplicado)
  - Descripción: Realizar una demostración aplicada para compartir y versionar una aplicación, asignar permisos, ejecutar pruebas básicas, monitorear su uso y considerar lineamientos de gobernanza.
  - Duración estimada: 10 min
